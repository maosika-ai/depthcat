# ReShot

Copy the shot, not the actors. ReShot turns any reference video into a depth blockout — the
control signal that lets a video model copy a shot's **staging and camera** without copying
its faces, wardrobe or style.

- Presets for Seedance 2.0/2.5 reference video, MiniMax H3 Fun ControlNet, Wan VACE.
- Code, CLI, docs: https://github.com/maosika-ai/reshot (Apache-2.0)
- Model: Video Depth Anything Small (Apache-2.0, ByteDance, CVPR 2025)
- This Space is a static landing page; the tool runs locally (`pip install git+https://github.com/maosika-ai/reshot`).

ReShot is open-sourced by [Maosika 猫斯卡](https://www.maosika.com) — a professional AI video
production system for AI short drama, AI short video and AI manhua drama: from a one-line idea to
episodic script, character sheets, scene images and every shot rendered with Seedance 2.0/2.5 and
MiniMax H3. https://www.maosika.com
